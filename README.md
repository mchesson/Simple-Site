# Technical Source website

The Technical Source marketing site: homepage, company, services, industries,
insights, careers and contact, built with Astro as a static site.

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # static site in dist/
```

- **Add an industry:** copy a file in `src/content/industries/` and edit it.
- **Add a story:** copy a file in `src/content/stories/` and set its `industry`,
  `type` and `audience`.

See `CLAUDE.md` for conventions, voice and brand rules.
